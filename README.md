# Omics2PK

**Experimental research code — NOT validated for clinical use.**

The project bridges [MultiOmics](https://github.com/rberrah/MultiOmics) exports to research on sample-specific gene networks (SWEET), literature-based mechanisms (Thesis Pillar A), and covariate identification for pharmacokinetics/pharmacodynamics (Thesis Pillar B / route R2).

## Current status

The repository was empty when accessed on 16 October 2026. This README initializes the default branch. The initial implementation, methods, tests and to-do list are proposed on a separate qualification PR.

No patient data, private Thesis code, inferred causal networks or validated PK predictions are stored or claimed here.

**Publishing policy:** public source files are separate from restricted clinical cohorts and controlled-access omics. No software license has been selected yet; an explicit owner decision is required.

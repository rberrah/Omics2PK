# Original HUMAN liver omics × measured CYP-substrate metabolism: source discovery (18 October 2026)

**Scientific question:** On the **same human liver donor**, is measured RNA sufficient to predict **measured enzymatic biotransformation or substrate-specific in-vitro CLint**, or does quantified protein, genotype and/or a third molecular layer improve real donor-heldout prediction? Prioritise **midazolam/CYP3A4, CYP2C8 substrates (tucatinib/imatinib), CYP2A6 substrate turnover and UGT substrate glucuronidation**. Metformin renal transporter-dependent AUC/CLr is NOT a hepatic-CYP metabolic benchmark.

## Evidence grades

- **PUBLISHED_MATCHED**: original authors measured multiple modalities and an in-vitro endpoint in identical liver donations. This **does not imply** we can download a donor-level numerical matrix.
- **PUBLIC_RAW_INDIVIDUAL**: actual numeric assay matrix is retrievable with original subject IDs, units and source/legal provenance. Each column and donor key must be independently verified. Do not infer this grade solely from abstracts, scatter plots or n.
- **MODEL_READY**: all source numeric x/y values and donor keys, specimen timing, physical units, censored outcomes and source rights validated. Reproduce independent published summary statistic(s), use exact same donors for every modality ablation and split by original donor.
- **UNQUALIFIED**: insufficient release/access evidence; no source-matched modelling claims.

Before model fitting require no accidental mixing of blood vs liver, RNA vs qPCR, liver donation/specimen identity, repeated assays vs independent donor, untreated basal abundance vs induced hepatocytes, observed midazolam clearance vs simulated PBPK. Compare identical donor subsets and identical heldout folds for **clinical / RNA / protein / clinical+RNA / clinical+protein / clinical+RNA+protein**, with training-only standardization and donor-group bootstrap. Add metabolomic third layer only if original same donors actually have measured untargeted metabolites and the same CYP substrate endpoint; absence of a third layer is **ABSTAIN**, not a negative finding.

**Planned primary statistical contrast:** donor-heldout MAE `clinical+RNA+protein - clinical+RNA`. One transcript per CYP measures *targeted transcript abundance*, NOT full transcriptomics, so do not generalize into 'all RNA versus multiomics'. A supplementary genotype-adjusted baseline should be used when original source genotype exists; do not describe in-vitro CYP probe activity as a separate omic layer.

## Biological note: metformin

Metformin is not significantly CYP-metabolized. Its actual human disposition focuses on **OCT/PMAT-mediated uptake / intestinal transport** and **OCT2/SLC22A2 + MATE1/SLC47A1 + MATE2-K/SLC47A2 renal secretion**. ABCB1/P-gp is not an established dominant intestinal or renal metformin driver. Existing original metformin E3 n32 is a true source-paired technical demonstration **with no convincing incremental metabolomic improvement**; it cannot substitute for hepatic CYP-specific PK evidence.

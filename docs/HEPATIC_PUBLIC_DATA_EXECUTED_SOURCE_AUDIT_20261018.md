## New actual GEO GSE9588 Omics2PK computation — molecular-network gate only

- Official source: FTP GEO `GSE9588_series_matrix.txt.gz`. Matrix: **427 unique GSM columns**, **39,302 genuine original processed array probes**, **GPL4372**. Numeric checks passed; raw microarray values remain transient.
- Train/test: **first 75 GEO sample columns** for fixed reference; **352 other GEO sample columns** as query-only projections. Test operates at GSM sample level; biological donor independence **not** confirmed, so do not describe as LODO validation.
- **24 unannotated array probes** chosen by TRAIN-only nonconstant variance, **NOT** CYP gene symbols or mechanistic pathway panel.
- Actual frozen, inductive reference code `src/omics2pk/inductive_sweet.py` generated graphs for all 352 queries using the unchanged training fingerprint; output aggregates only.
- **Historical v0 quality failure reproduced:** legacy `reference_add_query_v0` gives **238/352 unique graph hashes**, **114 hash collisions**, **117 similarity clamps** and **115 zero graph-update weights**. At zero weight v0 collapses to the same training-only reference graph, explaining the repeated nominally individual signatures.
- **Query-anchored v1 software improvement (real-source run 2026-10-22):** on the exact same 75-reference / 352-query GSE9588 matrix and 24 train-selected unannotated probes, `query_anchored_duplicate_v1` gives **352/352 unique graph hashes and 0 collisions**. This occurs because each query's own expression forms its query-specific anchor before the SWEET-like duplicate perturbation; even a zero update weight therefore does not collapse different queries onto one common reference graph.
- **Historical narrow-weight limitation:** with the same 24 unannotated probes used for both graph edges and sample-weight similarity, v1 has **117 clamped query weights / 115 zero weights**: 115 low, 2 high, mean similarity z **−1.757**, 69/352 queries at |z|>3, median unclipped position **0.156**.
- **Broader training-only sample-weight sensitivity (real-source run 2026-10-22):** keeping those 24 edge probes fixed but calculating sample weights from **512 finite, training-variable probes** reduces v1 clamps **117 → 24**, low clamps **115 → 22**, zero weights **115 → 22**, and |z|>3 queries **69 → 17**. Mean similarity z improves **−1.757 → −1.301** and median unclipped position **0.156 → 0.333**. v1 remains **352/352 unique graphs**. Legacy v0 also improves from 238 to **331/352** unique graphs (114 → 21 collisions), showing that much of its collapse was driven by the narrow weight universe.
- **Reference-order sensitivity:** with the broader 512-probe weighting fixed conceptually, a second reference selected 75 GSMs by deterministic SHA-256 rank of the source IDs, independent of expression and outcomes. Relative to broad-weight `first75`, v1 clamps fall **24 → 11**, low clamps **22 → 5**, zero weights **22 → 5**, and |z|>3 queries **17 → 1**. Mean similarity z recenters **−1.301 → −0.200** and median unclipped weight position rises **0.333 → 0.545**; 352/352 v1 graphs remain unique. This confirms that source-column ordering contributed materially to the earlier shift.
- **Reference-size sensitivity:** nested SHA-256 GSM references with broad 512-probe training-only weighting give v1 clamp fractions **4.51% (n50), 3.13% (n75), 3.67% (n100), and 0% (n150)**. The n150 run has 277 query samples, **0 low/high clamps, 0 zero weights, 0 |z|>3 queries**, mean similarity z −0.201 and 100% unique v1 graphs. Because n50→n100 is not monotonic, this single sequence does **not** establish 150 as a universal minimum; repeated outcome-free n150 splits are required.
- **Interpretation:** separation of a broad sample-weight expression universe from the targeted edge panel is materially important, source-order reference choice is important, and reference size affects tail calibration. However, 512 probes are **not genome-wide qualification**, hash selection is a neutral sensitivity device rather than a biologically optimized reference, and one zero-clamp n150 split is insufficient to define a production threshold. Probes remain unannotated, GSM→independent-donor identity is unverified, and there is no matched CYP activity outcome. Consequently `network_features_sufficiently_person_specific_for_individual_PK` remains **false**. Do not reinterpret improved calibration or unique v1 graph hashes as CYP function, predictive validity or official SWEET equivalence.
- Original HLC 398 per-human CYP activities still need the **source-proven original sample-ID join to 427 GEO GSM columns** (old Sage Commons / Synapse syn4499). Without this, ***no RNA-only vs phenotype*** predictive test can be performed on HLC, irrespective of successful expression software imports. Gene annotation would require source-matched GPL4372 manifest.

## Scientific answer to the user

**No reliable same-person numerical RNA+protein+drug metabolism original public matrix was qualified from the six newly searched primary papers.** Therefore this executed audit does **NOT** answer whether whole-transcriptome suffices versus genuine RNA+proteome for hepatic substrate metabolism. The published studies suggest proteins often track *functional activity* more closely than RNA, but reported within-sample correlation is not prospective heldout incremental error.

**What IS proven and reproducible now:** EPA shows targeted CYP RNA sometimes helps measured metabolism; Latham shows quantified CYP proteins plus functional phenotyping predicts measured in-vitro CLint but not yet RNA; GEO GSE9588 proves whole-expression input and network software can execute on 427 GEO samples but produces **nonunique individual graph signatures with this 24-probe test**, so is not yet qualified as person-specific omics covariates. Clinical metformin is a separate, neutral actual E3 study.

# Evidence-qualified public human omics + actual PK or PD sources (18 October 2026)

**Primary question:** prove that omic tissue/molecular measurements add **future** PK or PD predictive information beyond **true measured PGx genotype and clinical baseline**, on **the SAME biological patients and SAME outcome**; public article mention and study population n do not independently qualify joint original numeric matrices.

A metabolic enzyme functional assay measured from a donor liver is an E2 surrogate of hepatic metabolism, **NOT the donor's measured patient plasma drug AUC**, and an assay calculated using the same drug AUC cannot independently predict that very AUC without circularity. Drug-associated untargeted MS peaks collected at the same time as plasma drug are suitable for exposure *detection/nowcasting*, not necessarily for prediction *before treatment*. A metabolite sampled AFTER drug exposure is NOT a pretreatment pharmacokinetic covariate.

## Genotype baseline vs phenotype/omics: what study design actually proves

Prespecify nested patient- or *biological donor*-grouped comparisons on the **identical complete-subject intersection** and same outcome:

1. `clinical` (age, size, renal/hepatic function, co-medication, route/dose history, true correct sample time);
2. `clinical + genotype` using authentic, fully defined CYP/UGT/OATP allele calling with copy number/phase as needed; robust PGx baseline, never a single rs variant as though comprehensive star-allele panel;
3. `clinical + genotype + pre-treatment omics` (RNA CYP scores, protein abundance, baseline metabolome and/or molecular network);
4. `clinical + genotype + true independently measured prior enzyme activity` as a separately labeled **phenotyping comparator**, not an omic layer. Only if probe was administered **before** target drug and can meaningfully be measured in the intended recipient; terminal liver tissue lysate activities are not routine noninvasive clinical covariates;
5. `clinical + genotype + omics + prior phenotyping` **only** with all these original same-human data and appropriate prospective time ordering.

For E3 require genuinely measured individual drug **C(t), dose history, and assay time/units**. No derived exposure or same-drug metabolic ratio can be a predictor of the original exposure used to calculate it (outcome leakage). For E4 fit cross-validated PopPK IIV covariates for CL/F, absorption Ka/F, V/F and PD transit as warranted; externally validate C(t) and `ΔOFV, bias, relative RMSE, P20, calibration` under matched covariates. Dose-normalized *trough only* is not a full PK curve.

For PD, clearly distinguish: prognosis regardless of treatment, measured treatment-associated outcomes, causal treatment-effect heterogeneity requiring treatment-control and a proper estimation design, and mechanistic concentration-effect PK/PD requiring **actual same-person concentration/exposure and downstream longitudinal effect**. Baseline pre-treatment molecular samples only when predicting future outcomes; model differences between arms are observational/prognostic without proper interaction and causal diagnostics.

## Source/permission/redistribution

Existing *user-uploaded* Sage HLC individual original genotype/phenotype and 40k transcriptome data are NEVER redistributed. HLC source already allows original genotype vs RNA prediction of **in-vitro CYP substrate enzymatic activity**, but NO in-vivo drug PK or same-donor CYP protein data, so no proof of superior clinical omics covariates versus PGx.

CaPS original author GitHub data are **public**, but original repository LICENSE is **AGPL-3.0**; original individual records and author analysis code are not copied into this Omics2PK repository. The independent Python protocol pins source commit, computes hashes, fetches transiently, emits only aggregate summary. The user-uploaded HLC files are never fetched through CI or committed.
